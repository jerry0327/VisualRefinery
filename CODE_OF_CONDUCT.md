# Code of Conduct

VisualRefinery is intended to be a useful, welcoming open-source project for people working across many disciplines and levels of technical experience.

## Expected behavior

When participating in issues, pull requests, discussions, or reviews:

- be respectful and specific;
- critique ideas and artifacts rather than people;
- explain technical or design concerns with enough context to be actionable;
- welcome contributors who are unfamiliar with Agent Skills or visual-design terminology;
- give credit for ideas, examples, research, and assets;
- protect confidential or sensitive information;
- avoid harassment, discrimination, threats, or intentionally disruptive behavior.

## Project discussions

Design judgment can be subjective. When disagreeing, prefer evidence, user outcomes, accessibility, reproducibility, and clear trade-offs over taste alone.

Domain expertise should be treated with care: contributors should not imply credentials they do not have, and high-stakes domain guidance should be written so that uncertainty and review requirements remain visible.

## Enforcement

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary to protect the community.

If a concern should not be discussed publicly, use an appropriate private GitHub reporting channel.
