# Asset Manifest

Use this working document when the artifact includes external photographs, screenshots, icons, figures, maps, templates, or other third-party assets.

## Record at minimum

- where the asset came from;
- who created or owns it when known;
- whether usage is permitted;
- whether attribution is required;
- whether the file was modified, cropped, or annotated;
- where it appears in the artifact.

## Do not use

- watermarked images;
- assets with unclear rights when publication requires licensed material;
- screenshots exposing unnecessary private or confidential information;
- low-resolution assets that cannot survive the intended output size;
- generic filler when meaningful subject-specific evidence is available.
