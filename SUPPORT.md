# Support

VisualRefinery is an open-source project maintained through GitHub.

## Questions and usage help

Before opening an issue:

1. read the [Quick Start](README.md#-quick-start);
2. check the core [`SKILL.md`](skills/visual-refinery/SKILL.md);
3. review the relevant reference under [`skills/visual-refinery/references/`](skills/visual-refinery/references/);
4. run `python scripts/validate_skill.py` if the problem involves repository structure or a local modification.

For reproducible bugs, open a bug report and include the agent host, installation method, exact request, expected behavior, observed behavior, and any relevant output.

For ideas that broaden the workflow, use a feature request and explain whether the proposed change belongs in the core, an artifact branch, a domain profile, visual-design guidance, or QA.

## High-stakes domains

VisualRefinery can structure communication in medical, legal, financial, regulatory, engineering, and other consequential domains, but the skill does not replace qualified review or authoritative source verification.

When reporting problems in these areas, remove private, confidential, or personally identifying information from examples.

## Security

Do not use a public issue for security-sensitive reports. See [`SECURITY.md`](SECURITY.md).
