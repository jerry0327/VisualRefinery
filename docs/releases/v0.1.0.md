# VisualRefinery v0.1.0

The first public release of **VisualRefinery**: a domain-agnostic Agent Skill for transforming raw information into polished, evidence-grounded, publication-grade visual artifacts.

## What ships in v0.1.0

- A compact, portable `SKILL.md` built around the open Agent Skills convention.
- A six-stage workflow: **Evidence → Synthesis → Architecture → Design → Full-page QA → Delivery**.
- Progressive-disclosure references for:
  - visual design and accessibility;
  - slide decks, reports, one-pagers, posters, guides, technical explainers, and data-led artifacts;
  - optional cross-domain profiles;
  - full-page and technical QA.
- Reusable working templates for a claim ledger, asset manifest, and page-level QA log.
- Eight cross-domain eval prompts spanning strategy, academic research, engineering, training, travel, clinical teaching, public policy, and existing-artifact revision.
- Structural CI validation and repository contribution/security guidance.
- `plugin.json` metadata for Agent Plugins-compatible clients.

## Why this release matters

VisualRefinery started from a workflow used primarily for medical and travel artifacts. The public version removes those private assumptions and turns the underlying methodology into a general system for visual communication across disciplines.

Medical and travel guidance now live as optional domain overlays alongside business, research, education, engineering, data, policy, product, legal, financial, and editorial contexts.

## Install

### Agent Skills CLI

```bash
npx skills add jerry0327/VisualRefinery --skill visual-refinery
```

### GitHub CLI skill support

```bash
gh skill install jerry0327/VisualRefinery visual-refinery
```

### Manual / plugin package

Download the attached `visual-refinery-v0.1.0.zip`. It contains:

```text
VisualRefinery-v0.1.0/
├── plugin.json
├── LICENSE
├── README.md
└── skills/
    └── visual-refinery/
        ├── SKILL.md
        ├── references/
        ├── assets/
        └── evals/
```

A `SHA256SUMS.txt` asset is included so downloaded packages can be verified.

## Quality baseline

The v0.1.0 release is gated by repository CI. The validator checks the installable skill layout, required metadata, bundled references, resource links, the core skill size, and cross-domain eval coverage.

The core `SKILL.md` is intentionally kept well below 500 lines so specialized material can be loaded progressively rather than occupying agent context for every task.
